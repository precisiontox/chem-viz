Query Parameters

Filters of /api/chemical-info are combined with AND. A filter can be repeated (use=Pesticide&use=Pharmaceutical) or given comma-separated values; values of one filter are combined with OR. Matching is case-insensitive. Unknown parameters return an error, so typos do not go unnoticed.

Response Shape

Missing values are null; numbers are returned as numbers.

Errors

Errors are returned as JSON: {"error": {"status": 404, "message": "..."}}. Unknown chemicals and paths return 404; invalid or unknown query parameters return 400.

Usage

No authentication is needed. Responses allow cross-origin requests (CORS) and carry ETag and cache headers. If you use the data, please cite the PrecisionTox chemical library publication.
